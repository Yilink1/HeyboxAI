## 核心特性

- **原生无缝交互**
  - **精致原生感胶囊**：贴合小黑盒顶栏设计风格，深浅色主题自适应，支持长按临时收起
  - **灵活控制范围**：支持随时切换分析深度（仅看楼主 / 前 30 楼 / 前 100 楼 / 全帖讨论），长短帖皆省 Token
  - **多轮深度追问**：除了一键总结，还可随时追问帖子细节

- **完整长帖还原**
  - **突破 30 楼限制**：自动平稳加载长帖后续楼层，数百楼的热门大帖也能完整通读
  - **自动展开楼中楼**：深度挖掘折叠的神评与反转回复，还原完整讨论原貌
  - **智能精简纯净**：自动剔除纯表情、占位等无意义灌水，留存高价值干货，节省大模型 Token

- **平稳安全与体验细节**
  - **真人模拟浏览**：请求间隔平缓自然，避免突发高频，浏览更安心
  - **即时响应与打字机**：流式逐字输出，随时点击「停止」即刻中断，不浪费 Token 与电量
  - **纯矢量自绘图标**：所有按钮图标采用矢量代码绘制，杜绝部分机型出现彩色 Emoji 违和感

- **轻量透明，隐私保护**
  - **极简体积**：经深度混淆裁剪优化，APK 安装包仅约 1.5 MB
  - **本地端到端直连**：手机直接连通你选择的 AI 服务商，不经过任何第三方服务器，Key 与帖子数据绝不外泄

## 使用说明

1. **安装激活**：安装 APK，在 LSPosed 中启用模块，重启小黑盒即可
2. **配置使用**：在帖子页点击右上角 **AI** 胶囊打开面板，在设置中填入 API Key 即可开始使用

---

## 接口支持

兼容任何标准 OpenAI 格式接口（`/v1/chat/completions`）。支持直连 DeepSeek、OpenAI、OpenRouter、硅基流动、Kimi、智谱 AI 等服务商或自建聚合中转，填入对应 Base URL、API Key 与模型名即可直接使用。

## 常见问题与注意事项

**Q: 为什么安装后桌面上找不到软件图标？**  
A: 本模块为纯注入式 Xposed 插件，**不设桌面独立启动图标**。安装激活后直接在小黑盒帖子内使用即可

**Q: 清除小黑盒数据后会怎样？**  
A: 为保证读取速度与数据安全，模块配置保存在小黑盒本地。若在手机系统设置里清空了小黑盒的应用数据，重新填写一次 API Key 即可

**Q: 总结很长或者遇到网络错误？**  
A: 模块内默认包含 8 秒单页超时与 120 秒流式读取超时。如遇网络波动，可点击输入框上方的“重新生成”或尝试切换到前 50 楼等范围
